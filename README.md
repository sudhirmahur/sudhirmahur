## Projects

### Millio — Task & Workflow Management System
*Internal product*

Internal workflow platform built end to end — from concept to production.

- Product initiator and engineer for an internal workflow platform
- Built role-based access control (RBAC) with configurable permissions
- Designed task workflows with audit history and user action tracking
- Contributed to both backend logic and frontend interfaces
- Stack: Node.js, Express.js, React.js, MongoDB

### Wizly — E-commerce Platform

Full-stack e-commerce platform with an admin panel.

- Built product inventory, discounts, and a dynamic CMS backed by MongoDB
- Integrated Razorpay payment gateway, cart system, and order tracking
- Served 1000+ users in production
- Stack: MERN Stack, Redux, Tailwind CSS, Razorpay

### MingoBite — Food Platform

Food ordering platform with full CRUD and payments.

- Complete CRUD functionality for Users and Restaurant records (Node.js, MongoDB)
- Razorpay payment integration with cart management and real-time order status updates
- Responsive UI built with Bootstrap and Tailwind CSS
- Stack: MERN Stack, Redux, Tailwind CSS, Razorpay

### DNA Admin Panel

Admin dashboard for a medical education platform.

- Manages students, teachers, and courses
- Reusable React components with Axios API integration and React Router navigation
- Data filtering, search, and pagination for efficient content management
- Stack: React.js, Tailwind CSS
